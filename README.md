# shell-scripts
useful shell scripts

 - far uses ripgrep and sed to replace strings using syntax `far /path/to/dir/ "oldstring" "newstring"`
 - scroat is a screenshotting utility (grim/slurp on wayland) that can save, copy to clipboard, or upload to imgur (prints the url and delete hash, opens the url with xdg-open)
 - shutdown.sh is a zenity dialogue that prompts for logout/suspend/shutdown etc. this is mostly for use with sway/i3, but it's probably useful for other reasons

NOTE: this repo is a submodule for my dotfiles, so not all of the code here is mine, but all of the scripts provided are FOSS
